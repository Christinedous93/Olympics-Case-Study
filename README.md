# 📊 Olympic Medal Analysis - Power BI Dashboard

## 📷 Dashboard Preview

## 🎯 Project Overview
An interactive multi-page Power BI dashboard designed to analyze historical Olympic data, focusing on athlete demographics, medal distributions, and country performance dominance.

## 🛠️ Technologies & Tools
- **BI Tool:** Power BI Desktop (DAX, Power Query)
- **Visuals & Analysis:** Card KPIs, Bar Charts, Line Charts, and Key Influencers Visual.

## 💡 Key Pages & Dashboard Structure
1. **Cover Page:** Introduction and navigation hub.
2. **Medal Factors Page:**
   - **KPI Cards:** Total Athletes (114,701), Total Medals (32,873), Countries (208), and Sports (49).
   - **Medal Distribution by Age:** Breakdown of medals across age groups.
   - **Medal Distribution by Sex:** Comparison of medal achievements between Male (M) and Female (F) athletes.
   - **Factors Influencing Medal Achievement:** Utilizing the AI "Key Influencers" visual to analyze drivers of medal success.
3. **Country Dominance Page:**
   - **Top 5 Countries by Medals:** Ranking top performing nations.
   - **Medal Trends by Country:** Multi-year line chart tracking performance trends (e.g., Germany, Russia, USA).
   - **Medal Breakdown by Country and Sport:** Detailed matrix and bar charts analyzing sports-specific dominance (e.g., Swimming, Athletics).
